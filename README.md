# 🚀 Live Resume API (Azure Serverless)

## 📌 Overview
A production-ready serverless REST API built using Azure Functions.  
The API serves structured resume data in JSON format via a public HTTPS endpoint.

## 🔧 Tech Stack
- Azure Functions (Consumption Plan)
- Azure Storage Account
- Node.js
- REST API
- JSON
- GitHub
